# Easy Flow test build

1. Download the newest `app-debug.apk` from the latest successful **Build Android APK** action.
2. Allow installation from your browser or Files app when Android prompts.
3. Open Easy Flow and install **Moonshine Medium**. Keep the app open for the first download; an interrupted download resumes.
4. Tap **Enable keyboard**, enable Easy Flow in Android settings, then select it as your keyboard.
5. Tap the microphone key and dictate into any text field.

The APK is a debug-signed test build. Android may show an unknown-source warning because it is not distributed through Google Play.
